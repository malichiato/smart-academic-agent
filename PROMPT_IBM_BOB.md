# Prompt untuk IBM Bob

Salin prompt berikut ke IBM Bob untuk meminta peninjauan dan pengembangan proyek:

Buat/rapikan aplikasi web bernama Smart Academic Agent untuk membantu mahasiswa mengelola tugas kuliah. Gunakan HTML, CSS, dan JavaScript, desain responsif dan modern. Aplikasi harus memiliki dashboard total tugas/selesai/belum selesai/tugas mendekati tenggat; CRUD tugas (nama, mata kuliah, tenggat, prioritas, status); pencarian dan filter; serta AI Assistant yang menganalisis daftar tugas untuk menyarankan prioritas dan jadwal belajar. Simpan data di LocalStorage agar dapat dicoba tanpa backend. Pastikan aplikasi benar-benar berfungsi dan jangan mengklaim menggunakan model AI eksternal jika belum ada integrasi API. Mulai dengan memeriksa file yang ada, perbaiki bug, dan berikan langkah pengujian. Jika menambahkan API model bahasa, gunakan backend untuk menjaga API key dan dokumentasikan cara konfigurasi.

## Prompt pengujian
Saya memiliki tiga tugas:
1. Analisis Sistem, tenggat besok, prioritas tinggi.
2. Pemrograman Web, tenggat tiga hari lagi, prioritas sedang.
3. Sistem Informasi Akuntansi, tenggat lima hari lagi, prioritas sedang.

Tugas mana yang harus saya kerjakan terlebih dahulu? Berikan alasan dan saran jadwal pengerjaan.
